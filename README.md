### ⚡ Featured: Self-Healing Feeder

<a href="https://chau1912550.github.io/self-healing-feeder/"><img src="https://raw.githubusercontent.com/chau1912550/self-healing-feeder/main/docs/images/hero-3d.png" alt="3D model of the IEEE 123-bus feeder from the project's interactive report" width="100%"></a>

Machine-learning **fault location and automated restoration (FLISR)** on the IEEE 123-bus distribution feeder, simulated in OpenDSS.

| | Result |
|---|---|
| Faulted zone found, tested on buses never seen in training | **97.7%** vs 56.1% for conventional fault indicators |
| Average crew patrol after a lockout | **5.1 kft** instead of 39.0 kft (−87%) |
| Healthy load restored through tie switches | **2,670 kW**, every plan within ANSI C84.1 voltage, ampacity and radial limits |
| Where it fails | 92% of misses are weak ground faults (≥200 Ω); a 0.95 confidence cutoff removes 63% of errors |

**[Open the interactive report →](https://chau1912550.github.io/self-healing-feeder/)** a clickable 3D feeder model, error map, fault replay, full dataset and formulas, in English and Vietnamese · [Code](https://github.com/chau1912550/self-healing-feeder)
